01. 적용 범위

이 방침은 STOCKLY 웹·Android 서비스, 운영 서버의 계정 기능과 선택적인 Google Drive 자료 보관 기능에 적용됩니다. 이 공개 안내 사이트는 서비스 소개와 정책 문서를 제공하며, 로그인이나 Google 인증을 받는 화면이 아닙니다.

서비스는 관리자가 계정을 발급하는 베타 형태로 운영합니다. Google 로그인으로 일반 사용자 계정을 만드는 기능이나 공개 회원가입은 제공하지 않습니다.

관심 목록은 계정별로 저장합니다. 운영자는 서비스 운영을 위해 필요한 계정 정보에 접근할 수 있으며, 일반 사용자는 다른 사용자의 개인 관심 목록을 조회하는 기능을 제공받지 않습니다.

03. Google Drive 연결과 권한

연결 대상과 요청 범위

Google Drive는 운영자가 별도로 동의한 경우에 사용하는 저장 기능입니다. 요청 범위는 https://www.googleapis.com/auth/drive.file입니다. 이 범위로 앱이 생성했거나 사용자가 앱에 허용한 파일에 접근합니다. Drive 전체 파일에 접근하는 범위는 요청하지 않습니다.

운영자는 Google 인증과 폴더 선택 절차에서 stock_app 루트를 지정합니다. 서버는 지정 루트와 접근 가능한 하위 보관 파일을 확인하며, 다른 앱이 만든 기존 파일 전체의 권한을 자동으로 얻는 것은 아닙니다.

읽고 쓰는 내용과 사용 목적

서비스는 폴더 식별자·이름·파일 종류·접근 가능 여부, 보관 파일의 목록·식별자 등 필요한 메타데이터를 확인합니다. 수집한 시장자료와 분석 기록을 압축 파일과 완료 목록으로 업로드하고, 업로드 검증·과거 자료 조회·복원을 위해 해당 파일을 내려받을 수 있습니다.

저장 대상은 시장 가격, 뉴스·공시 메타데이터와 제공되는 요약, 실적·공매도·투자회사 관련 자료, 분석·예측·평가 등 공개 시장자료의 보관 기록입니다. 뉴스·공시 원문 전체를 무조건 저장하거나, 제공되지 않은 과거 자료를 만들어 저장하지 않습니다.

개인 로그인 계정, 사용자 이메일, 비밀번호 검증값, 세션과 개인 관심 목록은 이 Drive 보관 대상에서 제외합니다. Google 연결에 필요한 비밀 인증 정보는 서버의 별도 인증 저장소에서 관리하며 시장자료 묶음에 넣지 않습니다.

Google 데이터의 이용 제한

Google API로 접근한 데이터는 허용된 보관 파일의 동기화, 검증, 조회, 복원과 연결 상태 확인에 사용합니다. Google Drive 파일을 광고 타기팅, 개인 신용 평가 또는 범용 AI 모델 학습에 사용하는 기능은 제공하지 않습니다. 해당 데이터를 판매하지 않습니다.

STOCKLY의 Google API 정보 사용 및 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책과 해당하는 제한적 사용(Limited Use) 요건을 따릅니다.

연결 해제

운영자는 Google 계정의 서드 파티 연결 관리에서 앱의 접근 권한을 철회할 수 있습니다. 철회 후에는 서버가 새 자료를 업로드하거나 기존 Drive 자료를 읽는 데 실패할 수 있습니다. 권한 철회만으로 기존 Drive 파일이나 서버의 로컬 보관 자료가 자동 삭제되지는 않습니다.

04. 저장 위치·보관과 삭제

계정, 세션, 관심 목록, 시장자료의 색인과 분석 기록은 운영자가 관리하는 PC·서버의 영속 저장소에 보관합니다. Google Drive에 동기화한 시장자료는 운영자가 선택한 Google 계정의 저장소에도 남습니다. Google 인증이 만료되거나 동기화에 실패하면, 미전송 자료가 로컬에 대기할 수 있습니다.

개인 계정 정보와 관심 목록에는 일괄적인 자동 삭제 기간이 설정되어 있지 않습니다. 계정 비활성화는 로그인과 기존 세션의 이용을 차단하지만 계정 정보와 관심 목록을 즉시 삭제하는 동작은 아닙니다. 개인정보 삭제나 계정 이용 종료를 원하면 운영자에게 요청해 주세요. 본인 확인 후 적용 가능한 처리 범위와 시점을 안내합니다.

인증 세션은 기본 8시간 유효하며, 로그아웃·비밀번호 변경·계정 비활성화 등에 따라 종료될 수 있습니다. 만료된 세션과 로그인 제한 기록은 관련 서버 처리 시 정리됩니다. 이 기간이 계정 자체의 보관 기간을 뜻하지는 않습니다.

접속·호출 이력은 계정 DB 안에 저장하며 Google Drive나 시장정보 제공사로 전송하지 않습니다. 운영 기본값은 최근 90일·최대 10만 건으로, 용량 한도에 도달하면 오래된 기록부터 정리합니다. 조회에서는 보관 기간이 지난 기록을 제외하며 서버 처리 중 주기적으로 삭제합니다. 기존 로컬 복구 백업에는 백업 시점의 이력이 더 오래 남을 수 있으므로 백업의 보관·삭제는 운영자가 별도로 관리합니다. 이 기능을 적용하기 전의 접속 기록을 과거 데이터로 복원하지는 않습니다.

시장자료와 예측 기록은 과거 비교와 검증을 위해 누적 보관하며 일괄 만료일이 없습니다. 설정된 조건을 충족하고 Drive 복구가 검증된 오래된 로컬 압축 본문은 용량 관리 과정에서 회수할 수 있습니다. 이 경우에도 색인이나 Drive 보관 파일이 함께 삭제된 것으로 보아서는 안 됩니다.

Drive 보관 파일은 계정 소유자가 Drive에서 관리할 수 있습니다. 삭제하면 관련 과거 기록의 조회·복원이 어려워질 수 있습니다. 삭제 요청 시에는 로컬 저장소와 Drive 보관 파일 등 대상 위치를 구분해 운영자에게 알려 주세요.

05. 외부 서비스와 정보 제공

운영 서버는 연결한 시장정보 제공사에서 공개 시장자료를 가져옵니다. Google Drive는 운영자가 허용한 시장자료 보관에 사용합니다. 개인 계정 DB를 Google Drive 시장자료 보관 기능이나 시세·공시 제공사에 전송하지 않습니다.

뉴스·공시 원문, Google 계정 관리 등 외부 링크를 열면 해당 사이트의 개인정보처리방침과 이용 조건이 적용됩니다. 원문 사이트가 처리하는 정보는 STOCKLY가 직접 통제하지 않습니다.

이 공개 안내 사이트에는 자체 광고·분석 추적 스크립트, 외부 폰트, 입력 폼이나 쿠키를 설정하는 코드가 없습니다. 사이트를 제공하는 호스팅 사업자는 요청 처리와 보안을 위해 접속 정보를 처리할 수 있으며, 해당 사업자의 개인정보처리방침이 적용됩니다.

개인 계정 정보를 광고 목적으로 판매하는 기능은 없습니다. 법령상 요구가 있거나 이용자가 별도로 요청하는 경우에는 필요한 범위와 적용 조건을 확인해 처리합니다.

06. 접근 통제와 세션

서비스는 일반 사용자와 관리자 권한을 구분하고, 비밀번호 해시와 세션 해시, 로그인 시도 제한을 사용합니다. 서버의 인증 정보는 공개 안내 페이지나 Flutter 앱 번들에 포함하지 않습니다.

웹 앱은 로그인 유지를 위한 세션 쿠키를 사용하고, Android 앱은 기기 보안 저장소의 세션 토큰을 사용합니다. 웹 서비스의 필수 로그인 쿠키와 이 정적 안내 사이트의 동작은 서로 다릅니다. 브라우저에서 쿠키를 차단하면 실제 웹 앱의 로그인 기능이 정상 동작하지 않을 수 있습니다.

이러한 조치가 모든 사고나 정보 손실을 방지한다는 의미는 아닙니다. 계정 정보나 접근 권한에 문제가 있다고 판단되면 비밀번호를 변경하고 운영자에게 알려 주세요.
